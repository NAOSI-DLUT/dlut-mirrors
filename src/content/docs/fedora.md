## 镜像入口

[通过本站访问 Fedora](/fedora/)，请求会以 HTTP 302 跳转至 CERNET，再由其选择高校镜像站。

也可直接使用 `https://mirrors.cernet.edu.cn/fedora/`。

## 按版本配置

请参考 [CERNET Fedora 使用帮助](https://help.mirrors.cernet.edu.cn/fedora/) 选择适用的版本、架构与仓库子路径。修改软件源之前请备份原有配置，保留包签名校验。
