## 快速开始

### Ubuntu/Debian

```bash
sudo sed -i 's/archive.ubuntu.com/mirrors.dlut.edu.cn/g' /etc/apt/sources.list
sudo apt update
```

### CentOS/Fedora

```bash
sudo sed -i 's/mirrorlist.centos.org/mirrors.dlut.edu.cn/g' /etc/yum.repos.d/CentOS-Base.repo
sudo yum update
```

详细的配置方法请参考 [镜像文档](/docs/)。
