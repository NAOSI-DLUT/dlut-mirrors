上游地址：rsync://mirror.archlinux.org/arch/

## 快速配置

```bash
echo 'Server = http://mirrors.dlut.edu.cn/archlinux/$repo/os/$arch' | sudo tee -a /etc/pacman.d/mirrorlist
sudo pacman -Syy
```

## 适用场景

- Arch Linux
- Arch 衍生发行版

## 说明

如果您希望使用更稳定的镜像顺序，可以把本镜像地址放在 `mirrorlist` 前列。
