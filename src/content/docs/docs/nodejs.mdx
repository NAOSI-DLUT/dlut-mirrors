上游地址：rsync://mirrors.nodejs.org/nodejs/

## npm 配置

```bash
npm config set registry http://mirrors.dlut.edu.cn/npm
```

## yarn 配置

```bash
yarn config set registry http://mirrors.dlut.edu.cn/yarn
```

## 适用场景

- 前端开发
- Node.js 服务端开发
- CI/CD 依赖安装
